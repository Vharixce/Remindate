How to setup: Google Apps Script Emails

Remindate is a website without its own server, so a small script in your Google account sends the emails. Every minute it reads your synced notes from GitHub and emails the ones that are due, from your own Gmail. You only set this up once; after that it also works when your computer and phone are off.

  1. Turn on GitHub Sync in Remindate. Open GitHub Sync settings (bottom of the explorer), fill it in and tick Sync automatically after changes. The script only sees notes that are on GitHub.
  2. Create the script. Go to script.google.com → New project (sign in with the Google account that should send the emails). Click the title Untitled project and name it Remindate email reminders.
  3. Paste the code. Select all the example code in the editor and delete it, then paste the Remindate code:
    Press Ctrl+S to save.
  4. Check the time zone. Click the gear icon Project Settings on the left. The time zone should be yours (for the Netherlands: (GMT+01:00) Central European Time – Amsterdam/Brussels).
  5. Add your GitHub token. Still in Project Settings, scroll down to Script properties → Add script property. Property: GITHUB_TOKEN · Value: your GitHub token (the same one as in Remindate's GitHub Sync settings). Click Save script properties.
  6. Start it. Go back to the editor (<> icon). At the top, choose the function setup and press Run. Google asks for permission: Review permissions → choose your account → Advanced → Go to Remindate email reminders (unsafe) → Allow. “Unsafe” only means Google hasn't reviewed it: it's your own script. It needs: send email as you, connect to GitHub, run every minute. The log should say “Setup done. Found … notes … Checking every minute.” Error “Er is een serverfout opgetreden / A server error occurred”? That happens right after allowing. Just press Run again.
  7. Send a test email. Choose the function sendTestEmail and press Run. Check your inbox (and the spam folder the first time).
✅ That's it. In Remindate, tick Send Email Notification on a note and make sure it's synced. The email arrives within about a minute of the note's time.
Something not working?
  • “Add the script property GITHUB_TOKEN first”: step 5 is missing.
  • “GitHub refused the token”: the token expired or can't read your data repo. Make a new one and paste it in the script property.
  • “remindate.json not found”: GitHub Sync isn't on yet, or the repo name in the code doesn't match. Press Sync now in Remindate.
  • No emails: in Apps Script, Triggers should show checkReminders, and Executions a run every minute. If not, run setup again.
  • A normal Gmail account can send about 100 emails a day.
